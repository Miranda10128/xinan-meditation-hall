# 心安禅修堂 v4

免登录、零社交的中英双版静态禅修 PWA。使用仓库中的水彩全景与引导视频，无后端、统计、CDN 或外部字体。

## 运行与验证

```sh
python3 -m http.server 8000 --bind 0.0.0.0
node --test tests/engine.test.mjs
node --check app.js
node --check sw.js
```

没有安装依赖或构建步骤。main 推送由原有 GitHub Actions 部署 Pages：
https://miranda10128.github.io/xinan-meditation-hall/

## 入场与回访

首次访问自动显示一次精简说明；首屏有“随便坐，开始”和自主选席入口。默认使用画中前景空位（第 108 席），名字确认后开始当前整点场。已有名字与座位时显示欢迎回来，可一键坐回。普通入场不会随机覆盖已存名字；只有主动换名或输入自己的名字才改变身份。

自主选席用 seat_overview.png，34 个透明热区按图中可见蒲团定位（1–33 与推荐位 108），不把旧 108 席网格硬叠在新画面上。历史 1–108 席记录仍可坐回。画中人物是画面内容，不代表真实参与者，不显示参与数字；config.tonightCount 保持 null。

入场方式只有三个互斥选项：跟当前场（到本地整点结束）、从头开始（完整 60 分钟）、自己坐 20 分钟。计时条同时显示结束时刻和剩余时间。起身显示实际坐了多少分钟及下一场开始时间；不保存练习统计。

## 场景、视频与呼吸

- panorama_v3.webp 全屏铺底，可用手指或方向键左右平移。轻推镜、尘埃、案台烟、微光、窗外雾云和局部画景轻摆均由 CSS 合成，装饰层不拦截点按。页面隐藏时暂停动效与视频，音频独立；减少动态效果时取消场景动画。
- guide_stretch.mp4：0–1200 秒；guide_qizhi.mp4：1200–1260 秒；其余窗口与 20 分钟独坐使用 guide_still.mp4。使用柔边拱形竖版画框，所有视频始终 muted、音量 0、playsinline、loop，不混入其 AAC 音轨。
- 七支座期间自动显示 qizhi.png 浮层；可关闭且本段不反复弹出，段落结束自动收掉。菜单中可随时查看。
- 主画面的大呼吸环与提醒独立于底部设置。2100–2400 秒深呼吸使用吸 5／放松 2／呼 7／放松 2 秒；其余时间吸 5／呼 7 秒。“放松”不是要求屏息，不必追赶圆环。
- 设置与侧边菜单互斥。菜单提供 English／中文切换、每日一句、说明、坐姿图和本地供灯。

## 声音与时间表

默认无声，每次入座均需自己开启声音；旧声音偏好不会触发自动出声。开启后可见准备／播放／错误状态及音量，音量滑块可调。完全无声停止所有音频；“只要呼吸圈”关闭声音并隐藏视频；“只要音乐”播放音乐并隐藏视频与圆环。单独“开声音”保留圆环和视频。20 分钟模式也可以按需听音乐，不把可用的音乐选项做成无声假选项。

暂不提供“禅修引导语”档，不播放仍未就绪的引导录音。既有音频文件及引导词均未修改。音乐模式使用 music_bed.mp3，安顿窗口使用 music_anton.mp3 循环，收尾窗口用 music_shouwei.mp3；各活动窗口末 10 秒用 music_bridge.mp3 渐弱。开启声音时，所选场次起止各一声磬；无声时不敲磬。

engine.mjs 只删除旧息窗口，并把安顿从 1680–2100 改为 1500–2100；其余代码逐字保留。0–1200 压腿、1200–1260 坐姿、1260–1500 发心、1500–2100 安顿、2100–3180 呼吸练习、3180–3480 收尾音乐、3480–3540 收束、3540–3600 静候。沿用 index<7 的桥接规则，删除旧窗口后，收束窗口末 10 秒也进入音乐桥，静候窗口不另加桥。

music_anton 实测约 420.049 秒。播放器开启 loop，并以媒体实际时长取模定位，确保 10 分钟窗口里到 7 分钟后会重播；最后 10 秒仍切音乐桥。seg04_qingxi.mp3 旧文件未删除或改写，但运行时代码不再引用、生成或播放。

## 文件与替换

- index.html / style.css / app.js：页面、动效、视频、双语文案、交互与媒体。
- config.js：47 个安静名字、中文每日一句；英文对应文案在 app.js 内，不依赖外部翻译服务。
- assets/panorama_v3.webp、seat_overview.png、guide_stretch.mp4、guide_qizhi.mp4、guide_still.mp4、qizhi.png：从 ce94a3c 拉取，规格和原文件保持不变。
- assets/vendor/three.module.js：历史文件仍在，但启动、页面预加载和缓存清单均不再加载它。
- sw.js：版本 xinan-v1-5，缓存新图片、视频和应用文件；完整媒体缓存后支持 MP3/MP4 字节范围请求，便于离线视频循环。manifest 未改。替换同名素材后继续升级缓存版本。

所有个人数据仅保存在本地：名字、座位、语言、首次说明标记、音量、灯愿和每日一句索引，不保存打卡、连续天数或练习历史。灯愿上限 20 字，三日渐暗，与旧数据兼容。

## 验证与已知边界

自动检查覆盖首次入场与主动开声音、回访身份不被覆盖、三个互斥入场方式、计时标签、视频映射/静音、七支座图关闭与自动收起、安顿音频循环、呼吸节奏、音量/无声与视觉预设、20 分钟结束与告别、菜单互斥、中英文、供灯、全景平移、离线重开、MP4 Range 206；未发现页面脚本异常、Three.js 或外部请求。原有引擎测试更新窗口后通过，并新增安顿与桥接边界检查。

人工目视检查手机尺寸下的首次说明、欢迎页、选席图、练习画面、设置与英文菜单；这不等于真实 iPhone 操作验收。

iPhone 锁屏跨段续播仍需真机验证，浏览器后台可能延迟换轨；回前台会按实际时间校正。本地缓存可能被系统回收，未缓存的音频仍需联网。已有主屏幕应用请退出全部旧页面后重开，让新 service worker 激活，不要清除 localStorage，以免丢失名字和灯愿。

补充验证：34 个选席热区的中心均命中对应按钮；场次结束后重新开始能恢复声音入口，音量 0/100 可用键盘调节，展开设置时不会被另一声音浮钮遮挡；横屏与超宽屏无横向页面溢出，超宽屏背景铺满；新的英文浏览器自动使用英文说明（以后以用户手选语言为准）。

冷缓存模拟（390×844、4 Mbps／150ms）：完整场景约 2.34 秒可见，从首次进入、确认名字到主动开声音、音频与引导视频具备播放数据约 3.13 秒。此为自动化流程，不代表真实陌生人阅读和操作的实测结果，也不保证所有设备/网络的速度。真实手机、陌生人一分钟体验与锁屏行为仍需人工验收。

当前执行环境访问 Pages 域名被网络代理返回 403，线上直接打开受限；交付时分别汇报 Pages 工作流结果与直验限制，不把部署成功当成真人验收。
