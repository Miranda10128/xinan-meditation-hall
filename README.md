# 心安禅修堂 v3 · 三维大堂

中文静态 PWA，无后端、登录、统计或运行时外部资源。打开是俯瞰大堂，选席并确认名字后落座；在场景上拖动转头。右上角 ⋯ 收纳说明、每日一句和供灯，底部细条展开完整练习控制。起身、继续跟场与声音操作保持原有逻辑。

## 本地运行与校验

```sh
python3 -m http.server 8000 --bind 0.0.0.0
node --test tests/engine.test.mjs
node --check app.js
```

没有 npm 运行依赖或构建步骤。PWA 需 HTTPS 或 localhost。main 推送由原有 Pages 工作流部署。

## 文件与配置

- `app.js`：原有练习、声音、灯愿逻辑，以及 `createHall3D` 场景呈现。所有几何直接生成，不加载模型、纹理或 CDN。
- `assets/vendor/three.module.js`：官方 Three.js 0.160.1（r160）核心压缩发行文件，本地导入；来源、完整性校验与 MIT 许可证在同目录。
- `index.html` / `style.css`：极简角落控件、小名字卡片、底部练习面板和无 WebGL 的画景后备。
- `engine.mjs`：场次、计时、音乐桥、光线分类与灯衰减，未改。
- `config.js`：47 个安静名字与每日一句；`tonightCount` 保持 null，不显示任何参与数字。
- `sw.js`：版本 `xinan-v1-4`，CORE 新增本地 Three.js，其他缓存策略不变。manifest 不改。首次联网后可离线打开，音频首次请求后缓存；未听过的音频仍需联网，浏览器可能回收缓存。
- `assets/README.md`：真实素材与替换规则。音乐、磬声与第 1/2/4 组示意图已接入；seg01–seg06 引导语音仍为静音占位，stretch_3.png 仍为几何占位。本次未改素材。

## 三维空间参数

大堂木地板宽 38m、长 36m，立柱、横梁、低供台、简朴无五官供像、三层雾青远山均为低多边形几何。柔和环境光、暖光与雾由现有 `.light` 四档驱动，沿用引擎的本地时间分类。

108 个扁圆柱蒲团按 9×12 排，序号 1–108 不变。直径 1.1m；横向中心距 2.5m（净空 1.4m），前后中心距 2.6m（净空 1.5m），两侧保留过道。原有 button.seat 与 aria-label 保留供键盘和辅助技术使用；画面点选用 Three.js Raycaster，手机另有 10px 最近目标容差。

22 个无五官静坐人形是固定装饰，不代表真实参与者。固定席位：3、10、14、21、28、35、39、46、51、58、64、71、75、82、88、95、99、106、6、18、54、90。均匀分布；自己的席位上的装饰隐藏，不显示名字，也不接受互动。左右和前方可见范围取决于所选席与转头方向；最前排及最边席自然没有更前或更外侧的邻席，不凭空增加人形。

落座用 1.8 秒平滑插值到所选席，眼高 1.05m，朝向供台与正门。手指拖动/方向键可左右 ±40°、上下 ±15°；只转头，不平移。呼吸起伏周期 10 秒，幅度 6mm；减少动态效果时不滑行、不起伏，拖动直接跟手。起身回俯瞰，原席淡金标记保留，继续跟场回该席。

竖屏使用整屏 WebGL，俯瞰相机按纵横比拉远，以包含全部席位；落座后恢复真实眼高与透视，无横滑表单。初始像素比不超过 2，持续慢帧降至最低 1；渲染限制约 30fps。页面隐藏时取消渲染循环，回来恢复；音频与实际时间校正沿用原实现。WebGL 不可用或上下文丢失时，切回 hall.jpg＋9×12 画景座位和相同名字流程。

## 时间、隐私与已知边界

严格 60 分钟，保持原表整分边界：前七段末尾 10 秒音乐桥，58:00–59:00 收束，59:00–60:00 静候起身。跟当前场使用设备本地整点；从头开始独立计时；跳过压腿从七支座开始独立计时；20 分钟快捷入口独立计时。无声档连磬也不播放。名字、蒲团、声音偏好和灯愿只保存在 localStorage。

HTMLAudioElement 与 Media Session 在回前台时按真实时间校正。**iPhone 锁屏跨段续播仍不保证**，本次依要求不修，待真机验证。音乐素材与磬声虽真实，引导语音仍未录制；不要把静音占位当作真实教学。极低端或无 WebGL 设备使用画景后备。
