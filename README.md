# 晨光木堂：当前开发版本

晨光木堂手机测试版，开发分支 codex/morning-hall。固定测试入口：https://miranda10128.github.io/xinan-meditation-hall/ 。每次发布后刷新同一链接即可查看进度；进堂说明中也可刷新测试版。

## 启动

- 实时共修：`node server.mjs`，访问 http://127.0.0.1:4193/ 。仅监听本机。
- 静态演示：`node preview.mjs`，访问 http://127.0.0.1:4192/ ，包含六位明确标注的演示人物。
- 验证：`npm test`、`npm run check`。无需安装服务端依赖。

## 已实现

实时 Three.js 木堂、24 席、入口过渡、选座与取名、换席、第一/第三人称、左右看景。静坐、呼吸、音乐、预制 AI 女声引导，5/10/20/30 分钟，暂停与恢复。默认静音。

引导使用四条含留白的连续音轨，替换浏览器机器朗读；更长的课程增加静默，不拉慢字音。十二段文本经过自动转写核对，尚不能替代真人逐句听审。原 seg01–seg06 为静音占位，未使用。90 秒试听在 assets/narration/voice-preview-90s.mp3。

实时服务使用匿名临时会话、原子选席、SSE 同堂状态、心跳及过期释放。昵称和席位对同堂访客可见，不设聊天或注册，不持久保存访客日志。服务重启会丢失会话，客户端尝试恢复。本机后台不等于已经上线的多人服务。老师为模型配合预录 AI 音频，不是真人直播。

主要场景纹理使用 WebP（木纹已更新至v2），原先六张纹理合计约 1.68 MB；原 PNG 保留。离线缓存逻辑已实现，本机服务停止后的离线刷新、缓存配音及恢复连接已实测通过；真实 iPhone 锁屏、系统中断及跨公网设备尚待验收。

## 验证与剩余工作

21 项自动测试通过，包括原引擎、引导时间安排、占席冲突、过期、SSE、HTTP 范围及静态目录保护。Chrome 实际验证桌面18个空席、手机9个可见空席和18个列表空席；双页面同时选同席正确拒绝后提交者，离席及重连可同步。

连续五分钟音频已完整运行并正常到时结束；续坐从头播放，切换十分钟音轨立即生效。暂停前后 currentTime 均为7.737976秒，恢复后继续递增。MediaSession 控制已接入，但不能据此声称真实手机锁屏验收通过。

视觉仍未达到用户选定概念的最终质量。已增加人物细节、织物、藤编屋顶、植物影墙、庭院花池，但程序化人物和贴片庭院与概念图仍有差距。旧版功能如供灯、双语及整点场次尚未迁入。见 design-qa.md。

原平台文档保存在 design/v4-README.md；概念参考 design/morning-reference.png；素材许可证及原音乐来源见 assets/README.md。

静坐人物按材质合并为8组绘制；站立人物保留独立行走关节。默认使用较轻的基础光照。GTAO环境遮蔽仅保留在shadows=soft实验参数中，因显卡颗粒问题尚未验收；窄屏始终使用基础渲染。浏览器从返回缓存恢复时会重新建立会话，相关回归测试已补齐。

GitHub Pages 发布的是静态体验预览：六位演示同修，不代表实时在线人数。实时共修后台仍为本机服务，尚未部署公网。Pages只发布运行所需文件，不发布生成脚本、原始音频及本机日志。正式视觉验收仍未通过，本测试入口用于查看迭代进度。
