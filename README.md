# 心安禅修堂 v2 · 沉浸式大堂

免登录、零社交的中文静态禅修 PWA。无后端、数据库、外部字体或分析请求。

## 本地运行

```sh
cd /workspace/xinan-meditation-hall
python3 -m http.server 8000 --bind 0.0.0.0
```

浏览器打开本机 8000 端口。没有 npm 依赖或构建步骤。PWA 在 HTTPS 或 localhost 下生效。

```sh
node --test tests/engine.test.mjs
node --check app.js
node --check sw.js
```

## 文件与配置

- `index.html` / `style.css` / `app.js`：主页面、手机布局、交互与媒体。
- `engine.mjs`：本地整点场次、七处音乐桥、倒计时、光线与灯的衰减。
- `config.js`：`tonightCount` 是每日手动填写的历史参与数字；默认 null 隐藏，不伪造人数。每日一句与安静名字也在这里。
- `assets/`：任务包约定的同名素材与 PWA 图标；主图、音乐、磬声和第 1/2/4 组示意图已换为真实素材。替换方式见该目录 README。
- `manifest.webmanifest` / `sw.js`：安装及缓存。页面和图片安装时缓存；音频首次请求时完整缓存，支持 Safari 字节范围请求。未听过的音频仍需联网，浏览器可能回收缓存。
- `.github/workflows/pages.yml`：main 推送后运行引擎测试并部署静态文件。仓库 Settings → Pages → Source 需选择 GitHub Actions。

## 场次的已确认时间规则

严格 60 分钟，保持原表的整分边界。前七段末尾 10 秒为音乐桥，58:00–59:00 收束，59:00–60:00 静候起身，60:00 结束。跟当前场使用设备本地整点；从头开始独立计时；跳过压腿转为从七支座开始的独立场；静坐 20 分钟独立计时且只播放起止磬。无声档连磬也不播放，以文字提示。

默认首次无声。之后记住用户声音偏好与常坐蒲团；灯愿仅保存在 localStorage，以写入时间起算三日渐暗。页面不会因起身或整点自动开始新场。

## 手机验收与已知边界

音乐与磬声已接入；只有 seg01–seg06 分段禅修引导语仍为静音占位，第 3 组压腿示意图仍为几何占位。breath_loop.mp3 的现有素材说明见 assets/README.md；本次不更改素材或播放逻辑。

音频使用 HTMLAudioElement 和 Media Session，并在回前台时按真实时间校正。手机系统可能在锁屏时冻结 JS，使跨段换轨延后；因此**不能保证所有 iPhone/Safari 后台跨段连续播放**，需要真实设备完整验收。计时不会因后台停留而累积延误。若需要严格锁屏跨段无缝，后续应准备整场单一媒体文件或采用经真机验证的媒体方案。

桌面自动化不能替代 iPhone/安卓的锁屏、微信切换、主屏幕安装和真实 4G 首屏性能测试。隐私模式或禁用存储时，可继续静坐但无法持久保存偏好和愿望。

## v2 场景与名字

以真实 hall.jpg 的完整 16:9 画面为坐标系，9 排 × 12 列共 108 席。app.js 的 seatRows 用百分比定义每排纵坐标、左右端点和椭圆宽度，由后向前逐排展开、放大。宽屏完整包含画面，竖屏上下留白；横向溢出仅限场景自身，页面不横向溢出。

手机舞台实际最小宽为 960px（不低于任务包 640px 下限），保留后排热区与排间间隔，所有蒲团按钮至少 40×40px，可横向滑动。默认居中正门。选席后先弹出名字卡片，可换名或自起不超过 4 字的名字，确认后才开始计时与声音。随机入口每次随机选席与取名，普通选席默认沿用保存的名字。47 个去重后的安静名字在 config.js；名字仅存 xinan.name，席位仍存 xinan.seat。

确认后显示淡墨盘腿剪影、光晕与名字牌。以画面 50% 宽、38% 高为中心，用 1.2 秒 ease 推进至 1.25 倍；起身后推回全景，最后一个席位的标记保留并在重开页面后恢复。继续跟场跳过名字卡片，回到原席推进视角。系统减少动态效果时直接切换视角。练习区为场景底部浮层，可收起为状态行与呼吸圆圈，计时与播放继续。

计时引擎、声音播放与切换逻辑、供灯、manifest、service worker、素材及既有测试文件与 84cb1d3 基线一致。只更新了声音状态文案，纠正“所有音频静音”的旧说明。

本次依要求没有改 sw.js 或其 VERSION。已有安装设备若仍显示被旧 service worker 缓存的 v1 界面，需要清理站点缓存后联网重开（先自行保留本地灯愿和名字，勿删除 localStorage）；新设备首次访问不受旧缓存影响。此处没有偷偷改变 PWA 的缓存策略。
